# AERO·RAIL ARCHIVE | 翼轨档案

> **航空与铁道图鉴 · 涂装档案与微缩模型库**  
> *Aviation, Rail & Scale Model Encyclopedia: Liveries, Classic Retires & Diecast Archives*

---

## 🌟 项目简介 / Project Overview

**翼轨档案（Aero & Rail Archive）** 是专为全球民航爱好者（Aviation Geeks）、铁道迷（Railfans / Spotters）及模型收藏家（Scale Modelers）打造的现代数字化图鉴与退役档案馆。

本项目打破传统航空与铁道各自割裂的壁垒，在同一个页面上下文以**中英双语**深度收录：
- ✈️ **航空板块**：波音（747 空中女王、787、777…）、空中客车（A350 墨镜侠、A380、A320…）、协和式超音速客机（Concorde）、商飞 C919 等。
- 🚄 **铁道板块**：复兴号智能动车组（CR400BF-Z/AF-Z）、日本新干线（0系鼻祖、500系 EVA 初号机）、干线内燃/电力机车（东风4D“花东风/西瓜”）、经典退役列车等。
- 🎨 **涂装演变**：各航司/铁路局标准涂装、冬奥/大运彩绘、动漫联名、退役纪念复刻涂装。
- 🏛️ **退役经典名人堂**：记录机型/车型的服役历史、退役年份与全球现存博物馆打卡地。
- 📦 **微缩模型穿透档案**：深度关联真实载具与各大模型厂商（**Aviation400**、**JC Wings**、**GeminiJets**、日本 **KATO**、**TOMIX**，中国 **中车文创**、**长鸣火模** 等）的开模货号（SKU）、比例（1:400、1:200、N比例 1:150、HO比例 1:87）、工艺材质与绝版状态。

## 🛠️ 技术栈 / Tech Stack

- **核心框架**: React 19 + TypeScript + Vite
- **样式与设计语言**: Tailwind CSS + 工业制图暗色美学（Blueprint & Industrial Atelier）
- **图标系统**: Lucide React
- **部署平台**: Cloudflare Pages + GitHub

## 🚀 本地开发与构建 / Getting Started

### 1. 克隆项目
```bash
git clone https://github.com/heme9999/aero-rail-archive.git
cd aero-rail-archive
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run dev
```

### 4. 生产环境打包
```bash
npm run build
```
